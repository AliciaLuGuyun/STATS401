Design Description

In both treemaps, country rectangle area represents GDP because area makes part-to-whole relationships visible within the global economy. Green, gray, and red represent Increase, Unchanged, and Decrease because GDP status is categorical and the colors have familiar directional meanings. Continent and area labels, together with nested borders, show the hierarchy. Country labels appear when a rectangle has enough room; hovering always provides the full country, area, continent, GDP, and status. Keeping these encodings identical makes the tiling method the only major difference. Squarify generally produces more compact, square-like country rectangles, so labels and area comparisons are often easier. Binary recursively splits the available space, creating a more directional arrangement with some longer rectangles. It still preserves the same hierarchy and values, but the changed shapes and positions can make particular countries easier or harder to compare. Neither layout changes the underlying GDP data.

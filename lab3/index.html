Lab 3: Web Data Acquisition

Dataset Description

This dataset contains 1,200 county-level public health estimates. Each record includes the state, county, health category, measure, estimated value, unit, and year.

  • Source: CDC PLACES: County Data, 2025 release
  • Method: REST API acquisition with Python and requests
  • Records collected: 1,200
